Miniage v2 — браузерная MMORPG (PHP 8.1 + MySQL/SQLite + AJAX + Canvas)
=========================================================================

УСТАНОВКА НА ХОСТИНГ (5 минут)
-------------------------------

1. Распакуйте содержимое архива в каталог сайта (обычно public_html).
   Должно получиться так:

      public_html/
        index.php          ← точка входа
        install.php        ← установщик (удалить после установки)
        .htaccess          ← обязателен для «красивых» URL и защиты файлов
        src/  db/  assets/  var/

2. Откройте в браузере:  https://ваш-сайт/install.php

3. Установщик проверит сервер и спросит параметры базы:
   • MySQL — данные из панели хостинга (хост обычно localhost,
     базу и пользователя создают в панели);
   • или SQLite — если MySQL нет, база появится в var/miniage.sqlite.

4. Нажмите «Установить». Установщик создаст таблицы, наполнит игру
   предметами и монстрами и запишет .env.

5. УДАЛИТЕ install.php с сервера.

6. Зайдите на сайт. Демо-вход: demo / demo (если включали демо-аккаунты).
   Для боевого сервера лучше: SEED_DEMO=0 в .env (до установки) или
   удалить демо-аккаунт после и создать свой.

ТРЕБОВАНИЯ
----------
  • PHP 8.1 или новее
  • расширения: pdo, pdo_mysql (или pdo_sqlite), json
  • желательно: mbstring, openssl
  • права на запись в каталог var/  (chmod 775 var)
  • Apache с mod_rewrite и AllowOverride All
    (Nginx: try_files $uri $uri/ /index.php?$query_string;)

ЧТО ГДЕ ЛЕЖИТ
-------------
  index.php          фронт-контроллер
  src/Core/          конфиг, БД, сессии, роутер, миграции
  src/Service/       игровая логика: бой, опыт, магазин, чат
  src/Controller/    JSON API и HTML-страница
  db/schema.*.sql    схема для MySQL и SQLite
  assets/            CSS и JS (canvas-клиент)
  var/               SQLite-база и служебные отметки (закрыт от браузера)
  .env               создаётся установщиком; НЕ выкладывайте в git
  install.php        установщик; удалите после установки

БЕЗОПАСНОСТЬ
------------
  • .htaccess закрывает .env, var/, *.sql, *.md, *.log от скачивания.
    Если у вас Nginx — закройте эти пути в конфиге сайта:
        location ~* ^/(var/|\.env|.*\.(sql|md|log|sqlite))$ { deny all; }
  • install.php после установки удалить (он сам блокируется отметкой
    var/.installed, но лучше удалить файл).
  • Пароли: password_hash() (bcrypt/argon2). Слабые пароли отклоняются.
  • Есть лимиты: попытки входа, регистрации по IP, антифлуд чата.
  • Подробный отчёт по проверкам безопасности: SECURITY.md и BUGS.md
    (в полном репозитории).

ПРОВЕРКА ПОСЛЕ УСТАНОВКИ
------------------------
  Откройте https://ваш-сайт/api/health — должен вернуться JSON вида
      {"ok":true,"php":"8.1.x","db":"mysql", ...}
  Если видите 404 — не работает mod_rewrite; игра при этом открывается
  по адресу /index.php, а API-пути нужно настроить в веб-сервере.

ПЕРЕУСТАНОВКА
-------------
  Удалите var/.installed и откройте install.php заново. Данные не
  удаляются, схема применяется повторно (миграции идемпотентны).

ПОДДЕРЖКА РАЗНЫХ РАСКЛАДОК
--------------------------
  Архив рассчитан на «плоскую» раскладку (всё в одном каталоге).
  Вложенная раскладка из репозитория (public/ + src/ на уровень выше)
  тоже поддерживается: index.php сам находит корень приложения.
